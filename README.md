## 🌐 Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/Rishikrohit/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
